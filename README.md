# 诚辉餐饮静态 H5

广东诚辉餐饮管理有限公司《诚信经营 永创辉煌》的独立移动端长页。按原作品顺序收录 46 个区块，图片、拼图和图形全部随站点托管。

## 本地预览

在仓库根目录运行以下命令，然后打开浏览器访问 `http://localhost:8080/`。

```sh
python3 -m http.server 8080
```

## 部署和微信接入

将 `index.html`、`style.css`、`main.js` 和整个 `assets/` 目录放在同一 HTTPS 站点目录下。资源使用相对路径，支持部署在根目录或子目录，无需构建。

在小程序管理后台配置承载页面的业务域名。在小程序页面中，将 `web-view` 的 `src` 设置为部署后的完整 HTTPS 页面地址。

```xml
<web-view src="{{h5Url}}"></web-view>
```

## 内容维护

- `index.html` 中的区块按 `data-source-page` 顺序对应原作品。首屏后的目录直接定位主要章节。后续图片接近视口时加载。
- 证书、菜单和包含细小文字的原始图表保留在本地素材中，部分图片可点开查看大图。联系信息和公司简介另有可选择的网页文字。
- 地址按钮优先使用剪贴板接口，并兼容可用的选区复制方式。页面保留原生电话链接，地图使用本地静态图。
- 背景音乐默认关闭，点按页面右上角的音乐按钮后才会加载和播放。
- 正文图片使用 WebP，地图使用 PNG，拼图蒙版使用本地 SVG。发布新素材时更新素材目录版本和 `_headers` 中的 Cloudflare 缓存路径。
